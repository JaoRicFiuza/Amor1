# 💕 Galeria de Momentos - Para Meu Amor

Uma página web especial e interativa criada com amor, apresentando uma coleção de momentos especiais com uma proposta romântica.

## ✨ Características

- 🖼️ **Galeria de Fotos**: Exibição elegante de momentos especiais em uma galeria vertical
- 📱 **Design Responsivo**: Funciona perfeitamente em celulares, tablets e computadores
- ✨ **Animações Fluidas**: Animações suaves com GSAP e Lenis para uma experiência envolvente
- 💌 **Proposta Interativa**: Seção com pergunta "Você quer sair comigo?" com integração ao WhatsApp
- 🎨 **Design Moderno**: Interface elegante com gradientes e efeitos visuais

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica
- **CSS3**: Estilos modernos com gradientes e animações
- **JavaScript**: Interatividade e animações
- **GSAP**: Biblioteca para animações complexas
- **ScrollTrigger**: Animações acionadas por scroll
- **Lenis**: Rolagem suave e precisa

## 📋 Seções

1. **Início**: Apresentação principal
2. **Galeria de Momentos**: Fotos especiais em layout vertical
3. **Mensagem**: Mensagem pessoal de amor
4. **Proposta**: Pergunta especial com integração WhatsApp
5. **Rodapé**: Créditos

## 🔧 Como Usar

Simplesmente abra o arquivo `index.html` em um navegador web.
